# pd_ipc — CPU 版 PD 布料仿真器（进行中）

首期目标：**纯 CPU 的 Projective Dynamics 布料仿真器**，只含**距离约束 + pin**，跑通完整时间步并带渲染。
规划见 `docs/plan.md`，环境记录见 `docs/environment.md`，开发规范见 `docs/contributing.md`。

## 1. 构建与运行

```powershell
.\tools\build.ps1                 # 配置 + Release 构建
.\tools\build.ps1 -Clean          # 清理后重建

# 测试
.\build\Release\test_primitives.exe        # 距离约束的定义级不变量（全部通过）
.\build\Release\test_spring_vertical.exe   # 两顶点弹簧验收（部分失败，见 §4）

# 无窗口基准
.\build\Release\pd_bench.exe --grid 40 40 --steps 600 --iters 10

# 可交互查看器（GLFW + OpenGL）
.\build\Release\pd_viewer.exe
```

查看器交互：左键拖拽旋转 / 滚轮缩放 / `SPACE` 暂停 / `S` 单步 / `G` 重力开关 / `R` 重置 /
`[` `]` 调刚度 / `-` `=` 调迭代数 / `,` `.` 调子步数 / `;` `'` 调线程数 / `ESC` 退出。
HUD 用线段自绘（不依赖 ImGui 与字体文件）。

**构建注意**：源码含中文注释，必须让编译器按 UTF-8 读取（CMake 已加 `/utf-8`，
`tools/build.ps1` 另外设置 `CL=/utf-8` 覆盖手工编译场景）。详见 `docs/contributing.md` §4。

## 4. 约束方向问题已定位（本轮进展）

原先的 6 项失败来自**两个已经定位并修掉的真缺陷**，以及一个仍需收敛的环节。

### 4.1 已修缺陷 A：投影里存在标准 PD 没有的额外方向翻转

标准 PD 里 $d_c=\Pi_c(A_cx)=\ell\cdot\mathrm{unit}(A_cx)$，方向由 $A_cx$ **唯一决定**，
必须与矩阵块 $\kappa A_c^\top A_c$ 来自**同一个 $A_c$**。
我之前在投影里加了"强制指向自由端"的人为翻转，等于让两者来自不同的 $A_c$。

修复后 `_verify/standard_pd.cpp` 的逐项对照：

| 项 | 标准 PD 独立求解 | 代码组装 |
|---|---|---|
| $d_c.y$ | $-0.1$ | $-0.1$ ✓ |
| 散射 $-\kappa d_{c,y}$ | $+1000$ | $+1000$ ✓ |
| $L_{11}=m/h^2+\kappa$ | $10720$ | $10720$ ✓ |
| 一步解 | $0.101297528$ | $0.101297528$ ✓ |

### 4.2 已修缺陷 B：右端漏掉外力项 $-Mg$

标准 PD 的增量势能 $g(x)=\frac{1}{2h^2}\|x-\hat x\|_M^2+E(x)$，其中 $E=\Psi(x)-Mg\cdot x$，故

$$\nabla g=\frac{M}{h^2}(x-\hat x)+\nabla\Psi-Mg=0
\;\Longrightarrow\;
Lx=\frac{M}{h^2}\hat x+\sum_c\kappa_cA_c^\top d_c\;\boxed{-\,Mg}$$

**预测项 $\hat x$ 里的 $+h^2g$ 只是位置的一部分，不等于提供了外力。**
少了 $-Mg$，静止条件从 $\kappa(x-\ell)=mg$ 退化为 $-mg$，平衡跑到 $\ell-mg/\kappa$（差 $2mg/\kappa$）。
补上后无阻尼平衡从 $0.09995095$ 改善到 $0.1$。

### 4.3 仍需收敛的环节

无阻尼时实测平衡是 $0.1$（$=\ell$），而正确值是 $\ell+mg/\kappa=0.10004905$，仍差 $mg/\kappa$。
即"外力项已进入右端，但量级/配对仍不到位"。已经排除的：

- 投影方向与矩阵块符号（§4.1，已与标准 PD 逐位一致）
- 右端缺失外力（§4.2，已补，误差减半）
- 矩阵正定性（$\kappa uu^\top$ 与 $-\kappa I$ 两种偏离都会让布料发散，已排除）
- 阻尼建模（已改为 PD 的几何衰减形式 $M_\gamma=M/(1-k_d)$，与速度更新 $\times(1-k_d)$ 配对；
  这一项影响的是"阻尼下平衡随 $k_d$ 偏移"，与无阻尼偏差无关）

**下一步的定位方法（不再试符号）**：把"从 $y^\*=\ell+mg/\kappa$、$v=0$ 出发走一步"应得的
$L$、$b$、$x$ 三个量全部打印出来，与 $\nabla g=0$ 的解析式逐项相减，差值应该只剩一项 —— 那一项就是漏掉/多出的部分。
`_verify/steady.cpp` 已经确认"从 $y^\*$ 出发会漂走"，说明 $y^\*$ 不是当前离散格式的不动点。

### 4.4 当前可运行状态

- 布料**稳定有界**（20×20 网格 600 步：单步 0.08 ms，平均应变 12.1%，最大 26.9%）
- 预分解复用正常（符号分解 1 次、数值分解 1 次）
- `test_primitives` 44 断言 / 3 项失败（失败的是我按中间结论改过的符号断言，需随最终定论统一）；
  `test_spring_vertical` 6 项失败，根因同上。
- **符号定死前不要做刚度标定**（否则会把错误固化进默认参数）。
