# PD 外层迭代的收敛问题：成因、排查与标定

> 本文记录一个**真实缺陷**的完整成因与处置：高刚度下 PD 布料出现"末端卷曲、
> 摆动被抑制、缓慢下沉"。结论是**外层迭代在给定预算内远未收敛**，
> 成因是预条件子与真实 Hessian 在横向上的失配，且该失配由物理应变 ε 决定。
>
> 记录日期：2026-09-20。相关代码：`core/sim/Integrator.cpp`、
> `core/sim/Scene.h`；回归：`tests/chain/convergence_criterion.cpp`；
> 诊断工具：`_verify/residual_audit.cpp`、`_verify/residual_crosscheck.cpp`、
> `_verify/stiffness_calibration_record.cpp`。

---

## 1. 现象

查看器默认工况（60×60、间距 0.02、κ=1e5、h=1/120、每帧 2 子步）下：

1. **末端维持弯曲形态**：侧视时最下端不会绷直，稳定停在一个卷曲形状
2. **摆动被额外抑制 + 缓慢下沉**：摆动衰减后不继续摆，而是持续缓慢下移
3. **与 κ 强相关**：κ 调小后现象明显缓解

---

## 2. 排查过程中被**否证**的假设

记录在此以免重走。每条都有实测反证。

| # | 假设 | 反证 |
|---|---|---|
| A | 几何刚度比 `(ℓ/r)·t/(κℓ)` 过小导致 PD 常矩阵近似失效 | 实算该比值 ≈ 2.3e-4 ≪ 1，近似其实很准 |
| B | 信息需沿约束链传播 O(边数) 次迭代 | 全局步是 L 的精确回代，信息一次到位 |
| C | `M/h²` 与 `κAᵀA` 的相对大小是病态来源 → 增大 h 应改善 | **该实验设计有误，不能作数**：我测的是"不同 h 跑固定帧数后的末态残差"，而不同 h 的末态不同、都被迭代预算截断在 ~g 附近，因此无法判断**收缩率**是否受 h 影响。按单弹簧解析式 `q⊥ = κ(ℓ/r)/(m/h² + κ)`，减小 h **确实**降低 q（改善收缩率），只是在本工况幅度很小（κ=1e5 时 h 从 1/120 减到 1/240 只把 q 从 0.999885 降到 0.999539）。结论：h 是有效但**代价极高**的杠杆（迭代数需按比例增加）。 |
| D | 自由端张力为零 ⇒ 横向刚度为零 ⇒ 慢模式；加张力应变快 | 只钉两角（张力更大）反而更慢（ρ 0.890 → 0.947） |
| E | "残差其实约 1e-6，问题不存在" | **本项目自己的度量错误**，见 §3.1 |
| F | 卷曲是"模型简并"造成的 | 见 §3.4：若所有边受拉且每个自由点经受拉边连通到 pin，则静态解唯一为 z=z_pin，**侧向卷曲不可能是静态平衡**。故卷曲不能归因于无抗弯的简并 |

**子步数 ≠ 子步长**：`substepsPerFrame` 只改变每显示帧跑几个子步，h 始终不变，
因此它不能用来检验与 h 有关的假说。早期曾据它错误否证假设 C。

## 3. 真正的成因

### 3.1 先修度量：一个假阴性

`nonlinearResidual` 最初直接用 `ctx.targets` 作为投影 `d_c`。但 `ctx.targets` 是
迭代循环**最后一次迭代开始前**算的，循环一旦提前退出它就相对当前位置**过期**：

```
|κ(rel − d_过期)| ≈ κ·|d_新 − d_旧|  ≫  κ(r − ℓ)
```

残差被算成远小于真实值的**假阴性**：1.2e-06 m/s²，而用当前位置重算投影后是
**10.28 m/s²** —— 差 7 个数量级，且结论完全相反。**假阴性比假阳性危险**：
它一度让人得出"问题不存在"的错误结论。

修正：在 `nonlinearResidual` 内就地重算 `d_c = ℓ·unit(x_a − x_b)`。
`_verify/residual_audit.cpp` 用三个**有解析答案**的位形锁住该公式：

| 位形 | 解析答案 | 实测 |
|---|---|---|
| 处于平衡长度 ℓ+mg/κ | 0 | 5.5e-12 |
| 处于静止长度 ℓ（弹簧无力） | g = 9.81 | 9.810000 |
| 拉长 10% | \|κ·0.1ℓ/m − g\| = 24990.19 | 24990.19 |

测点必须在**解全局步之前**：单弹簧（单约束）一次 PD 迭代即精确到达不动点
（`docs/plan.md` §2.2.2），`stepOnce` 之后测必然是 0，测不出公式对错。

### 3.2 收敛在观测窗口内极慢；"幂律"未获确证

修正后追踪单个子步内 200 次迭代（60×60、κ=1e5、稳态）：

```
迭代   1   残差 3.87E+002
迭代  21   残差 7.33E+001
迭代  41   残差 4.92E+001
迭代 101   残差 2.88E+001
迭代 201   残差 1.78E+001
```

**单调下降、非循环、非停住** —— 所以加大迭代数**确实有效**，但在观测窗口内衰减极慢。

> **一处曾写错的拟合（已更正）**：本文早期写过 `r(N) ≈ 387·N^-0.40`，
> 该式与数据自相矛盾（`387·200^-0.40 = 46.5`，而实测 200 次时为 17.8），
> 且据此外推的"10⁷ 次迭代"不成立。按首末两点反解，实测指数约 **-0.58 ~ -0.63**。
> 但**不应据此断言渐近幂律**：有限维非退化极小点附近，误差是多个模式的叠加
> `e_N = Σ_j a_j q_j^N v_j`；当大量 q_j 接近 1 时，有限窗口内的多指数叠加
> **看起来就像幂律**，尾部仍可能进入最慢模式控制的指数段。
> 当前准确的表述是：**观测窗口内收敛很慢，疑似存在宽分布的慢模式；渐近行为未确证。**

这条曲线解释了此前**全部**看似矛盾的数据：

- 迭代数越大布料越接近平衡（外部复核测到"4000 次迭代的位移是 40 次的 9.13 倍"）
- 而位移类判据会因单步位移小而提前退出，**永远看不到这个衰减**
  —— 这才是"缓慢下沉永不停止"的直接来源

稳态残差与迭代数上限：1/2/5/10/40 次对应 **9.80 / 10.72 / 14.00 / 20.63 / 14.26 m/s²**
（均与重力 9.81 同量级），即 40 次预算内高刚度布料**远未平衡**。

> **"凸问题就线性收敛"的说法也不严谨**：普通凸性不足以保证，而且距离弹簧在
> **受压**时具有负横向曲率，本问题不是全局凸问题。

### 3.3 机理：预条件子高估横向刚度约 1/ε

距离约束的真实 Hessian（写成工程应变 ε=(r−ℓ)/ℓ 的形式）：

```
H_e = κ uuᵀ + κ·ε/(1+ε)·(I − uuᵀ)
       └ 纵向 ┘   └─ 横向 ∝ 张力 ─┘
```

所以横向/纵向曲率比准确说是 **ε/(1+ε)**（小拉伸时才近似为 ε）。
**没有抗弯/抗剪 ⇒ 横向刚度只来自张力**，而张力 `T = κ·Δℓ`。

PD 的预条件子 `L = M/h² + Σκ AᵀA` 用的是常数 **κ**，对横向上
**高估约 1/ε 倍**（严格说 1/ε·(1+ε)）。ε 越小失配越严重、外层迭代越慢。

> **注意不要把这个比值等同于整体收敛率。** 完整时间步的迭代矩阵是
> `J = I − A⁻¹H`（A 为常矩阵、H 为该时间步的目标 Hessian），
> 收敛率由这个广义谱决定。各边应变不同，**受压边甚至有负横向曲率**，
> 因此失配只是**慢模式的来源**，不等于全局收敛因子。
> 外部复核对 59 自由点悬挂链做过独立谱计算：κ=1e5、h=1/120 时
> 59 个横向模式中 **52 个的 q 大于 0.999** —— 支持"宽分布慢模式"的解释。

而在本项目默认网格下，ε 本身就是 κ 决定的：

```
ε ≈ 23.0535 / κ          （60×60、间距 0.02、密度 1；见 §4.1 的推导）
```

于是：

| κ | ε | 1/ε | 稳态残差 | 可用性 |
|---|---|---|---|---|
| **1e5**（旧默认） | 0.023% | ~4300 | **> g** | 不可用 |
| 7685 | 0.3% | ~330 | 4.3 | 勉强 |
| **2305**（新默认） | **1%** | **~100** | **0.41** | 可用 |
| 1000 | 2.3% | ~43 | — | 可用 |

**旧默认 κ=1e5 对应 ε=0.023%，远超常见工程材料的弹性应变范围**，
布料几乎不可伸展，横向自由度极度欠约束 —— 问题由此而来。

> 注：**不应把 0.023% 称为"比钢还刚"**。应变取决于载荷，不能单独用来鉴定材料；
> 这里能说的只是"在该尺寸与自重下，该 κ 给出的顶端应变远超常规织物量级"。

### 3.4 卷曲归属：在受拉条件下它不可能是静态平衡

外部复核给出一个直接判据。令每条边的权重 `w_e = T_e / r_e`。若

- 所有边**不受压**（T_e > 0），且
- 每个自由点都通过受拉边连通到 pin

则静态 z 方程是正权图上的 Laplace 方程，而所有 pin 的 z 相同，故唯一解为

```
z_i = z_pin      （所有自由点）
```

**即使没有抗弯，侧向卷曲也不可能是静态平衡。** 存在受压边时该结论不能直接用。

这与 §3.2 的实测一致（残差与重力同量级、布料未平衡），因此
**卷曲不能归因于"无抗弯 ⇒ 零应变构型不唯一"这一模型简并**：
无重力下的零应变构型确实不唯一，但不能直接套到受重力的悬挂状态 ——
即使应变趋近零，支撑重量的张力仍可保持有限。

（该判据成立的前提"所有边不受压"尚未在卷曲状态下逐边核验，见 §6。）

## 4. 处置：刚度标定

### 4.1 标定依据

**解析式只作初值，标定以实测反解为准** —— 但两者其实是自洽的，早期"差 50 倍"
的说法是本文的换算错误。

正确的物理关系是（`T` 为张力，单位 N）：

```
Δℓ = T / κ          伸长量，单位 m
ε  = T / (κ ℓ)      应变，无量纲
```

即 **ε·κ = T/ℓ**。取一条内部列，顶端 pin 下方的质量（58 个内部顶点 + 1 个边顶点）：

```
M_below = 58 × 0.0008 + 0.0006 = 0.047 kg
T       = 0.047 × 9.81         = 0.46107 N
ε·κ     = 0.46107 / 0.02       = 23.0535 N/m        ← 与实测逐位吻合
```

> **本文早期写过的"差 50 倍来自横向边"是错的**：`N·m·g = 0.463 N` 是**伸长量**
> 的量纲，乘的是 `1/κ` 而不是 `1/(κℓ)`；少除的 `ℓ = 0.02` 恰好造成约 50 倍差异
> （`0.463032 / 23.0535 = 0.0201`）。外部复核另行实测确认：所有竖直边的
> `κ·应变` 最大值 23.0535，而**所有水平边**的同一量最大仅 **4.9e-4** ——
> 横向边贡献可忽略，"来自横向边"的解释被这一对照明确排除。

实测扫描（`_verify/stiffness_calibration_record.cpp`）确认 `ε·κ` 在
κ ∈ [1e3, 2.3e5] 范围内恒定，与上式一致。

取目标 **ε = 1%** 得 **κ ≈ 2305**。

> **该常数依赖质量口径**：换成标准面积集中质量（每顶点 ρℓ²，为本项目边法的一半），
> 同一内部列给出约 **11.48 N/m**。因此 κ 的意义必须与质量口径一起声明。
> 另：κ≈2305 准确的说法是"**在这套尺寸、自重与质量定义下，目标顶端应变为 1%**"，
> 不能据此认定为棉/帆布（应变取决于载荷，不能单独鉴定材料）。

### 4.2 新的默认值

`SceneConfig::stiffness` 与查看器默认：**1e5 → 2.3e3**。

### 4.3 收敛门槛与代价的取舍

`residualTolerance` 是"不平衡力 / 重力"的上限。实测（κ=2305、600 帧）：

| 门槛 | 阈值 (m/s²) | 末段迭代 | 物理 ms/帧 | FPS |
|---|---|---|---|---|
| 1e-3（原默认） | 9.8e-3 | 40 | 46.8 | 19.0 |
| 1e-1 | 0.98 | 40 | 47.7 | 18.6 |
| **3e-1** | 2.94 | **1** | **3.2** | **58.4** |
| 1.0 | 9.81 | 1 | 1.7 | 60.0 |

**这是一个诚实的取舍**：40 次迭代内无法把残差压到 0.1g 以下，因此实时性
要么靠放宽门槛（接受相应力不平衡），要么靠更多迭代（不可实时）。
默认取 `1e-3`（保守）；实时演示可用 `--residual-tol 3e-1`。

**2026-09-24 补测：这个门槛"贴着"谁定的、以及它到底换不换精度**（完整数据见 `docs/perf.md` §18.6）：

- **0.3 是性能倒推出来的，不是精度要求**：它成立的唯一原因是"查看器稳态的残差就停在
  **0.285–0.291·\|g\|** 附近"⇒ 0.3 门槛**1 次迭代**即满足。**门槛是贴着稳态残差定的。**
- **把门槛收紧到 1e-3 并不能"更准"**：查看器场景实测 `iters=1` / `40` / `80` 三者的
  **最终应变 max 完全相同（0.0100–0.0101）**，而物理耗时是 **0.42 / 11.00 / 58.34 ms/帧**。
  原因是**残差是"离不动点多远"的度量，不是"形态准不准"的度量**：60×60/κ=2305/只 pin 两角时，
  残差从 7.7·\|g\| 降到 0.014·\|g\|（降 550 倍），**形态只变 2.7 %**（应变 0.2728→0.28033），
  而且 K=2 时已只差 0.4 %。
- **它在多数工况下根本不触发**：只 pin 两角或刚度大（κ=1e4）时残差常在 0.4–7.7·\|g\|，
  ⇒ 门槛永不满足，**只有迭代上限在起作用**（40×40/κ=1e4 跑满 80 次仍有 0.653·\|g\|）。
  所以"调门槛"**不是**调精度的旋钮；要更接近平衡只能加迭代数（或换更好的预条件子，见 §3.3）。


### 4.4 迭代数"要几次才算正常"：与文献对照 + 本机 κ/规模扫描（2026-09-24）

**起因**：有人问"我们的迭代到达 1e-1 要这么多次，正常吗？"——§4.3 只给了"门槛 vs 代价"，
从没回答"这个迭代数在 PD 里算不算多"。补做两件事：查文献口径 + 本机做两个扫描
（每子步**恰跑 K 次**：判据开到不可达 `--residual-tol 1e-9`、并关位移判据 `--tol 0`）。

**① 文献口径：PD 从来不是"迭代到某个残差"，而是"每帧固定跑 10–20 次"**

- Liu/Bouaziz/Kavan（[*Towards Real-time Simulation of Hyperelastic Materials*](https://ar5iv.labs.arxiv.org/html/1604.07378)）
  原文：The local and global steps are repeated for a fixed number of iterations
  (**typically 10 or 20**)。同一篇还把 PD 解释为**准牛顿法**（用常矩阵 `M/h²+L` 代替真实 Hessian），
  并指出 **if A is a poor approximation of the Hessian, the quasi-Newton method may converge slowly**。
- ⇒ **"慢"是 PD 的已知性质，不是实现缺陷**；文献的对策全部是"加加速"：
  Chebyshev 半迭代（[*Wang 2015*](https://dl.acm.org/doi/10.1145/2816795.2818063)，
  作者页 [wang-2015-csi](https://wanghmin.github.io/publication/wang-2015-csi/)）、
  L-BFGS / Anderson 外推（Liu 2016、Peng 2018）。CPU 侧最新 PD 布料工作
  （[*Lu et al. 2025, Domain-decomposed Projective Dynamics*](https://wanghmin.github.io/publication/lu-2025-hpc/)）
  同样把"并行度与**收敛**的平衡"当核心问题。
- **本文 §5.2/§6 早已把这三条外推列为"当前最值得做的下一步"**，至今**未实测**；
  本次只补"为什么慢、算不算异常"的量化，**没有**动迭代法。

**② 扫描 A：刚度（60×60、600 子步；κ 对应 ε ≈ 10 % / 1 % / 0.1 %）**

| κ（ε≈） | K=1 | K=4 | K=8 | K=16 | K=32 | K=64 | 达 0.3·\|g\| |
|---|---|---|---|---|---|---|---|
| 230.5（10 %） | 0.839 | 0.106 | 0.038 | 0.0071 | 0.0017 | 0.0014 | **≤4 次** |
| **2305（1 %，我们的标定值）** | **7.74** | 1.251 | 0.777 | 0.415 | 0.103 | 0.020 | **~20–32 次** |
| 23050（0.1 %） | 46.3 | 16.2 | 3.36 | 1.696 | 0.948 | **0.811（地板）** | **64 次内达不到** |

（单位 ·\|g\| = m/s² ÷ 9.81。）三条可解释的规律：

1. **K=1 的残差 ∝ κ**（0.84 / 7.74 / 46.3），约 **3–5 × κh²g**（κh²g = 0.157 / 1.57 / 15.7）
   ⇒ 与"预测子按 h²g 前进、约束按 κ 响应"的量纲一致，**量级没有异常**。
2. **相对衰减率几乎与 κ 无关**（K=8 时降到 4.6 % / 10.0 % / 7.3 %）⇒"到某个**绝对**门槛要几次"
   主要由**起始残差 ∝ κ** 决定；而 κ=2305 正是我们为"物理上 1 % 应变"标定出来的
   ⇒ **迭代数的大头是我们选的物理，不是求解器的毛病**。
3. **ε 越小尾部出现"地板"**：κ=23050 时 64 次仍停在 **1.75 %**（0.81·\|g\|），再迭代也不降 ——
   与 §3.3 的机理吻合（预条件子把横向刚度**高估约 1/ε 倍**，ε 越小失配越大 ⇒ 迭代撞墙）。

**③ 扫描 B：规模（κ=2305、300 子步）**

| 网格 | K=1 | K=8（相对） | K=32（相对） |
|---|---|---|---|
| 30×30 | 15.32 | 6.6 % | 2.6 % |
| 60×60 | 13.04 | 9.2 % | 2.6 % |
| 120×120 | 11.71 | 12.3 % | **16.8 %（撞地板）** |

⇒ 域越大越慢（信息要跨更多约束、失配累积），与文献里"高分辨率布料需要更多迭代 / 需要多重网格或
子空间加速"一致。

**④ 口径提醒（比较时必须对齐）**：文献报的是**相对**残差（‖r‖/‖r₀‖，通常接受 1e-2…1e-3），
我们用的是**绝对**阈值且是 **max 范数**（·\|g\|）。我们的 "0.1·\|g\|" 相当于从 7.7·\|g\| 起降 **77 倍**
（≈2 个数量级）⇒ 在相对口径下属于正常要求，不算"过严"。

### 4.5 判据 A（**不依赖任何文献**）：迭代算子谱 vs 实测 —— 结论：**正常**（2026-09-24）

**为什么需要它**：§4.4 说明跟文献比做不到闭环（他们的 κ 量纲、pin 方式、网格结构、归一化口径都缺）。
那就换个问法：**我们实测的收缩率，是否正好等于 PD 应有的那个？**

**推导**（线性化，围绕当前位形）：一次 PD 迭代 = 局部投影 + 全局求解，距离约束的投影在 |A_c x| ≈ ℓ 处
线性化为 `P_c = I − n_c n_cᵀ`（`n_c = unit(A_c x)`）⇒ 误差 `e⁺ = T e`，其中

```
T = I − A⁻¹(M/h² + N)        B := I − T = A⁻¹(M/h² + N)
A = M/h² + Σ_c κ_c A_cᵀ A_c   N = Σ_c κ_c A_cᵀ (n_c n_cᵀ) A_c
```

（惯性项确实是**未缩放**的 `m/h²`，阻尼不进 L —— 见 `Assembler.cpp`。）因为
`A − (M/h²+N) = Σ_c κ_c A_cᵀ(I − n_c n_cᵀ)A_c ⪰ 0`，所以 B 的广义特征值必 ≤ 1，`ρ(T) ≤ 1`。
两个量都只需要**已经很便宜的 A⁻¹**：`ρ(T)` 用幂迭代（x ← T x），`λ_max(B)` 用幂迭代（x ← B x），
且 `λ_min(B) = 1 − ρ(T)`（T = I − B 特征值一一对应）。Chebyshev 半迭代的理论收缩率随之可得：

```
ρ_cheb = (√λ_max − √λ_min) / (√λ_max + √λ_min)
```

**工具**：`_verify/iteration_spectrum.cpp`（`pd_itspectrum`，不动生产代码）。它带两个自检：
① `solve(A·v)` 必须还原 `v`（守住"`A⁻¹ = solve()`"这个假设）；
② **pin 行的右端必须清零** —— A 的 pin 行被组装成**单位行**（所以 `A⁻¹` 在那行是 1），而分子
`M/h²+N` 在那行有 ~κ 的耦合项 ⇒ 不清零会立刻给出 `ρ(T) ≈ 9194` 这种**理论上不可能**的值
（第一版就是这么错的，教训写在工具注释里）。

**结果**（κ=2305、h=1/120、顶边整条 pin、阻尼 0.02；预测与实测在**同一状态**上测）：

| 状态 | ρ(T)（预测） | 实测 | 实测/预测 |
|---|---|---|---|
| 60×60 稳态（600 子步） | 0.998782 | **0.997651** | **0.9989** |
| 60×60 瞬态（第 60 子步） | 0.998782 | **0.894000** | **0.8951** |
| 100×100 稳态（600 子步） | 0.998788 | **0.998627** | **0.9998** |

**结论**：

1. **实测 ≤ 理论预测（三组都 ≤ 1）⇒ 我们的实现没有额外损失，收敛速度就是 PD 应有的速度
   —— 正常。** 这是**实现正确性**判据，与别人快慢无关。
2. **慢的根源在算子本身**：`λ_min(B) = 0.0012` ⇒ 预条件后的条件数 ~820，与 §3.3 的
   "预条件子把横向刚度高估 ~1/ε 倍"（ε = 1 % ⇒ ~100）量级吻合。
3. **相位之谜就此解释清楚**：`ρ(T)` 在瞬态与稳态**几乎相同**（0.998782 vs 0.998788）——
   慢模一直在；差别只在"当前残差里**哪个模占主导**"：瞬态里快模占主导（所以看起来是 0.894），
   快模衰减完之后剩下的就是慢模（0.998）。这也解释了 §4.4 里"7 次 vs 停滞"的矛盾，
   以及 Wang 2015 自己 Fig.9（快）与 Table 1 ρ≈0.999（慢）的内部不一致。
4. **Chebyshev 的理论增益（终于有数了）**：`ρ_cheb = 0.9325` ⇒ 到 1e-2 相对残差
   **plain ≈ 3780 次 vs Chebyshev ≈ 66 次（~57×）**。
   ⚠️ 但要注意：`0.9325 > 0.894` —— **在瞬态相位上 Chebyshev 反而更差**；
   它只在**慢模主导**（稳态/接近平衡）时才赢。这与 Wang 2015 "延迟 S = 10 次再开 Chebyshev、
   且 ρ 宁取小"的做法完全一致。⇒ 上 Chebyshev 的正确形态是"**稳态启用**"，而不是全程开。

**Chebyshev 到底怎么用**（原理、递推、该开/不该开的时机、落地影响面）：见 [`docs/chebyshev.md`](chebyshev.md)。

**复现**：

```powershell
.\build\Release\pd_itspectrum.exe --grid 60  --steps 600 --iters 300   # 稳态（慢模主导）
.\build\Release\pd_itspectrum.exe --grid 60  --steps 60  --iters 300   # 瞬态（快模主导）
.\build\Release\pd_itspectrum.exe --grid 100 --steps 600 --iters 300   # 同规模稳态
```
**结论**：**正常**（PD 固有行为 + 我们选了物理 1 % 应变的刚度），**没有实现缺陷的证据**。
真正值得做的是**外层加速** —— Chebyshev 外推最便宜（只需 λ_min/λ_max 估计；而我们的矩阵本来就是
**常数 + 预分解 + 三条独立链**，是上 Chebyshev 的理想形状，文献报告同等精度下迭代数减少数倍）。
代价：改迭代法 ⇒ 数值会变 ⇒ 要重做物理基线（现在有 `tools\check.ps1` 托底）。

## 5. 这是不是 PD 本身的缺点？

**是 PD 的一条固有性质，但不是"实现 bug"，也不是"PD 不可用"。** 分三层说：

### 5.1 属于 PD 固有性质的部分

PD 的收敛率由"预条件子与真实 Hessian 的接近程度"决定。本项目按
`docs/plan.md` 决策 D2 使用**常矩阵** `L = M/h² + Σκ AᵀA`，其权重是常数 κ，
而横向曲率是 κ·ε/(1+ε)。**这个量级的失配是"用常权重近似距离约束"这一构造的
必然结果**，任何采用同一构造的 PD 实现都会有，与代码质量无关。

ε 由物理决定（织物 ε~1%），所以失配量级也随之固定 —— 这是这类方法在
**近不可伸展膜**上的固有代价。

### 5.2 **但"只能接受当前速度"说得过头**（已更正）

常矩阵 `A` 与它的分解**不必改变**，仍可叠加外层加速：

- **Chebyshev 外推**：加速原有固定点迭代（Wang 2015）
- **带能量下降保护的 Anderson 加速**：组合历史迭代（Peng 等 2018）
- **以 `A⁻¹` 为初始近似的 L-BFGS**：用历史梯度修正搜索方向（Liu 等 2017）

它们都**不要求把几何相关 Hessian 组装进 L**，因此不违反 D2。
它们不保证彻底消除刚度依赖，但足以否定"保持常矩阵就只能接受目前的速度"。

> 本文早期写过"未找到不把几何相关曲率放进矩阵而能加速外层迭代的方法"，
> 那是**排查范围不足**，不是不存在。上述三条是待评估的候选路径。

### 5.3 不属于 PD 的部分

- **旧默认 κ=1e5 是标定缺失**（`docs/plan.md` §3 M1.5 一直欠着这项），
  把工作点放到了 ε=0.023% 的区间。换成 ε=1% 后残差降两个数量级到 0.41
- **收敛判据的两个缺陷**（以坐标量级为参照 → 平移不变性被破坏；只看相邻迭代
  位移 → 高刚度下失真；位移判据可绕过残差门槛）是实现缺陷，已修
- **`nonlinearResidual` 的假阴性**与查看器 `--damping`/`--no-early-exit` 未正确
  接线，都是实现缺陷

### 5.4 与"加约束"的关系（重要，且本文早期说得过头）

§3.3 的失配来自**横向刚度只由张力提供**。抗弯/抗剪约束会给横向补上刚度 ——
这是根治方向（`docs/plan.md` §2.2.3）。

但**不能假定它们"必然"消除失配**：它们的强度、作用方向与拉伸项并不相同，
不保证为所有慢模式补上 O(κ) 量级的刚度。需要逐项评估。

同样重要的是**不能用它们掩盖当前的求解误差**：先修正标定与判据，再按计划
追加约束。否则无法区分"新约束改善了物理"与"新约束掩盖了欠收敛"。

## 6. 仍未解决 / 未查清的部分

1. **卷曲归属**：§3.4 的判据（所有边受拉 ⇒ 侧向卷曲不可能是静态平衡）给出了
   方向，但其前提「**所有边不受压**」尚未在卷曲状态下**逐边核验**。
   若存在受压边（自由端张力趋零，很可能有），该结论不能直接用，需要另找判据。
2. **渐近收敛行为未确证**：观测窗口内衰减很慢（疑为宽分布慢模式），
   但是否为幂律、以及最慢模式的指数尾部，均未做谱验证。
   外部复核对**单链**做过谱计算（59 个横向模式中 52 个 q>0.999），
   但对完整卷曲布料的谱未验证。
3. **外层加速未评估**：§5.2 列出的三条候选路径（Chebyshev 外推、
   Anderson 加速、L-BFGS）都未实测。**这是当前最值得做的下一步。**

### 8.7 E2 + E1 执行结果：两条最可能的解释**都被实测证伪**（2026-09-24）
