# PD 外层迭代的收敛问题：成因、排查与标定

> 本文记录一个**真实缺陷**的完整成因与处置：高刚度下 PD 布料出现"末端卷曲、
> 摆动被抑制、缓慢下沉"。结论是**外层迭代在给定预算内远未收敛**，
> 成因是预条件子与真实 Hessian 在横向上的失配，且该失配由物理应变 ε 决定。
>
> 记录日期：2026-09-20。相关代码：`core/sim/Integrator.cpp`、
> `core/sim/Scene.h`；回归：`tests/chain/convergence_criterion.cpp`；
> 诊断工具：`_verify/residual_audit.cpp`、`_verify/residual_crosscheck.cpp`、
> `_verify/stiffness_calibration_record.cpp`。

---

## 1. 现象

查看器默认工况（60×60、间距 0.02、κ=1e5、h=1/120、每帧 2 子步）下：

1. **末端维持弯曲形态**：侧视时最下端不会绷直，稳定停在一个卷曲形状
2. **摆动被额外抑制 + 缓慢下沉**：摆动衰减后不继续摆，而是持续缓慢下移
3. **与 κ 强相关**：κ 调小后现象明显缓解

---

## 2. 排查过程中被**否证**的假设

记录在此以免重走。每条都有实测反证。

| # | 假设 | 反证 |
|---|---|---|
| A | 几何刚度比 `(ℓ/r)·t/(κℓ)` 过小导致 PD 常矩阵近似失效 | 实算该比值 ≈ 2.3e-4 ≪ 1，近似其实很准 |
| B | 信息需沿约束链传播 O(边数) 次迭代 | 全局步是 L 的精确回代，信息一次到位 |
| C | `M/h²` 与 `κAᵀA` 的相对大小是病态来源 → 增大 h 应改善 | 实测 h 扫 48 倍范围（0.1 → 0.00208），稳态残差稳定在 ~11 m/s²，**对 h 不敏感** |
| D | 自由端张力为零 ⇒ 横向刚度为零 ⇒ 慢模式；加张力应变快 | 只钉两角（张力更大）反而更慢（ρ 0.890 → 0.947） |
| E | "残差其实约 1e-6，问题不存在" | **本项目自己的度量错误**，见 §3.1 |

**子步数 ≠ 子步长**：`substepsPerFrame` 只改变每显示帧跑几个子步，h 始终不变，
因此它不能用来检验与 h 有关的假说。早期曾据它错误否证假设 C。

## 3. 真正的成因

### 3.1 先修度量：一个假阴性

`nonlinearResidual` 最初直接用 `ctx.targets` 作为投影 `d_c`。但 `ctx.targets` 是
迭代循环**最后一次迭代开始前**算的，循环一旦提前退出它就相对当前位置**过期**：

```
|κ(rel − d_过期)| ≈ κ·|d_新 − d_旧|  ≫  κ(r − ℓ)
```

残差被算成远小于真实值的**假阴性**：1.2e-06 m/s²，而用当前位置重算投影后是
**10.28 m/s²** —— 差 7 个数量级，且结论完全相反。**假阴性比假阳性危险**：
它一度让人得出"问题不存在"的错误结论。

修正：在 `nonlinearResidual` 内就地重算 `d_c = ℓ·unit(x_a − x_b)`。
`_verify/residual_audit.cpp` 用三个**有解析答案**的位形锁住该公式：

| 位形 | 解析答案 | 实测 |
|---|---|---|
| 处于平衡长度 ℓ+mg/κ | 0 | 5.5e-12 |
| 处于静止长度 ℓ（弹簧无力） | g = 9.81 | 9.810000 |
| 拉长 10% | \|κ·0.1ℓ/m − g\| = 24990.19 | 24990.19 |

测点必须在**解全局步之前**：单弹簧（单约束）一次 PD 迭代即精确到达不动点
（`docs/plan.md` §2.2.2），`stepOnce` 之后测必然是 0，测不出公式对错。

### 3.2 残差按**幂律**极慢衰减

修正后追踪单个子步内 200 次迭代（60×60、κ=1e5、稳态）：

```
迭代   1   残差 3.87E+002
迭代  41   残差 4.92E+001
迭代 101   残差 2.88E+001
迭代 200   残差 1.78E+001        拟合 r(N) ≈ 387·N^(-0.40)
```

**单调下降、非循环、非停住** —— 所以加大迭代数**确实有效**，但次线性：
要降到 0.01·g 约需 **10⁷ 次迭代**，不可用于实时。

这条曲线解释了此前**全部**看似矛盾的数据：

- 迭代数越大布料越接近平衡（外部诊断测到"4000 次迭代的位移是 40 次的 9.13 倍"）
- 而位移类判据会因单步位移小而提前退出，**永远看不到这个衰减**
  —— 这才是"缓慢下沉永不停止"的直接来源

稳态残差与迭代数上限：1/2/5/10/40 次对应 **9.80 / 10.72 / 14.00 / 20.63 / 14.26 m/s²**
（均与重力 9.81 同量级），即 40 次预算内高刚度布料**远未平衡**。

### 3.3 机理：预条件子高估横向刚度约 1/ε

距离约束的真实 Hessian（`docs/plan.md` §2.2.1 记过）：

```
∇²E_c = κ[(1 − ℓ/r) I + (ℓ/r) u uᵀ]
         └─ 纵向 κ ─┘   └ 横向 ∝ 张力 t ┘
```

**没有抗弯/抗剪 ⇒ 横向刚度只来自张力**，而张力 `t = κ(r−ℓ) = κ·ε·ℓ`，
故横向/纵向 = **ε**（当前应变）。

PD 的预条件子 `L = M/h² + Σκ AᵀA` 用的是 **κ**，对横向上
**高估了约 1/ε 倍**。ε 越小失配越严重、外层迭代越慢。

而在本项目默认网格下，ε 本身就是 κ 决定的：

```
ε ≈ 23.05 / κ          （60×60、间距 0.02、密度 1；实测标定，见 §4）
```

于是：

| κ | ε | 横向失配 1/ε | 稳态残差 | 可用性 |
|---|---|---|---|---|
| **1e5**（旧默认） | 0.023% | ~4300 | **> g** | 不可用 |
| 7685 | 0.3% | ~330 | 4.3 | 勉强 |
| **2305**（新默认） | **1%** | **~100** | **0.41** | 可用 |
| 1000 | 2.3% | ~43 | — | 可用 |

**旧默认 κ=1e5 对应 ε=0.023%，是"比钢还刚"的量级**（钢的弹性应变约 0.1%），
布料几乎不可伸展，横向自由度极度欠约束 —— 问题由此而来。

## 4. 处置：刚度标定

### 4.1 标定依据

**解析式只作初值，标定以实测反解为准。** 竖直链张力上限 `N·m·g` 给出的
`ε_top = N·m·g/κ` 与实测差约 **50 倍** —— 差值来自为维持宽度而被拉紧的
**横向边**（纱线外张时会拉长水平约束），解析式没有计入。

实测关系（`_verify/stiffness_calibration_record.cpp`）：

```
ε_max · κ ≈ 23.05      （60×60、间距 0.02、密度 1，κ 取 1e3~2.3e5 范围内恒定）
```

取目标 **ε = 1%**（棉/帆布的弹性伸长量级）得 **κ ≈ 2305**。

### 4.2 新的默认值

`SceneConfig::stiffness` 与查看器默认：**1e5 → 2.3e3**。

### 4.3 收敛门槛与代价的取舍

`residualTolerance` 是"不平衡力 / 重力"的上限。实测（κ=2305、600 帧）：

| 门槛 | 阈值 (m/s²) | 末段迭代 | 物理 ms/帧 | FPS |
|---|---|---|---|---|
| 1e-3（原默认） | 9.8e-3 | 40 | 46.8 | 19.0 |
| 1e-1 | 0.98 | 40 | 47.7 | 18.6 |
| **3e-1** | 2.94 | **1** | **3.2** | **58.4** |
| 1.0 | 9.81 | 1 | 1.7 | 60.0 |

**这是一个诚实的取舍**：40 次迭代内无法把残差压到 0.1g 以下，因此实时性
要么靠放宽门槛（接受相应力不平衡），要么靠更多迭代（不可实时）。
默认取 `1e-3`（保守）；实时演示可用 `--residual-tol 3e-1`。

## 5. 这是不是 PD 本身的缺点？

**是 PD 的一条固有性质，但不是"实现 bug"，也不是"PD 不可用"。** 分三层说：

### 5.1 属于 PD 固有性质的部分

PD 的收敛率由"预条件子与真实 Hessian 的接近程度"决定。本项目按
`docs/plan.md` 决策 D2 使用**常矩阵** `L = M/h² + Σκ AᵀA`，其权重是常数 κ，
而真实横向刚度是 κ·ε。**这个 1/ε 的失配是"用常权重近似距离约束"这一构造的
必然结果**，任何采用同一构造的 PD 实现都会有，与代码质量无关。

也不能靠调参消掉：ε 由物理决定（布料就是 ε~1%），而失配 = 1/ε 随之固定。
它就是这类方法在**近不可伸展膜**上的固有代价。

### 5.2 不属于 PD 的部分

- **旧默认 κ=1e5 是标定缺失**（`docs/plan.md` §3 M1.5 一直欠着这项），
  把工作点放到了 ε=0.023% 的极端区间。换成 ε=1% 后残差降两个数量级到 0.41
- **收敛判据的两个缺陷**（以坐标量级为参照 → 平移不变性被破坏；只看相邻迭代
  位移 → 高刚度下失真）是实现缺陷，已修
- **`nonlinearResidual` 的假阴性**与查看器 `--damping` 未接线，都是实现缺陷

### 5.3 与"加约束"的关系（重要）

§3.3 的失配来自**横向刚度只由张力提供**。加入抗弯/抗剪约束会给横向补上
O(κ) 量级的刚度，失配随之消失 —— 这确实是根治方向（`docs/plan.md` §2.2.3）。

但**不能用它来掩盖当前的求解误差**：先修正标定与判据，再按计划追加约束。
否则无法区分"新约束改善了物理"与"新约束掩盖了欠收敛"。

## 6. 仍未解决 / 未查清的部分

1. **卷曲与下沉的确切因果链尚未闭合**。已确证的是：40 次预算内残差 ≥ O(g)、
   布料未达平衡（§3.2），且残余运动随迭代数增加而持续（§3.2 引用的 9.13 倍）。
   但"卷曲形态"是否**完全**由欠收敛造成、还是也含模型本身的简并（无抗弯 ⇒
   零应变构型不唯一），尚未用实验分开。
2. **为什么残差是幂律衰减而非指数**。PD 对凸问题是线性收敛；观测到的
   `r ~ N^-0.4` 提示迭代矩阵的谱在近不可伸展极限下向 1 堆积，
   但未做谱分析证实。
3. **未找到在不引入几何相关曲率进矩阵（D2 禁止）的前提下加速外层迭代的方法**。
   已否证的杠杆见 §2；`κh²/m` 与 h 都不可用。
